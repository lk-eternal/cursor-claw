# 验收问题报告

> 变更 ID：`20260627132014-飞书临时会话工作目录可选`

## 第 1 轮

### 反馈问题

桌面端通道配置页（`src/renderer/components/ChannelPanel.tsx`）未体现管理员创建临时会话时可选 `-dir` 工作目录的说明。用户在配置界面中只能看到「允许其他人使用」相关文案（`允许其他人使用开启后该通道响应其他人私聊及群聊 @消息（在按通道隔离的临时目录中运行）`），找不到 `-dir` 能力说明。

### 归因结论

| 字段 | 值 |
|------|-----|
| 结论 | 代码实现问题 |
| reason | `code` |

### 判定依据

| 维度 | 说明 |
|------|------|
| PRD 验收标准 #8 | 要求「面向管理员的使用说明或内置帮助」可查到可选工作目录三条要点（如何指定、默认规则、创建成功反馈含目录）。 |
| PRD 交互节 | 要求帮助/说明文案中须告知可选目录及默认规则。 |
| 实现范围 | T4 仅更新了 `src/daemon.ts`、`electron/daemon-manager.ts` 的 `/help` 文案，未更新 `ChannelPanel.tsx` 等桌面配置页帮助文案。 |
| 非目标澄清 | PRD 非目标排除的是「主工作目录的配置界面」改动，非排除全部 Settings 帮助文案；配置页作为管理员查阅通道能力的入口，应体现 `-dir` 说明。 |

### 影响范围

- 组件：`src/renderer/components/ChannelPanel.tsx`（通道配置页帮助文案缺失）
- 场景：管理员在桌面端查阅飞书通道能力说明时，无法获知 `/chat new -dir <path>` 可选工作目录能力
- 必要时：`Settings` 帮助区可能需同步补充（视 UI 结构而定）

### 后续处理

- 路径：`/kb-apply` 或追加任务
- 修复方向：在 `ChannelPanel.tsx`（及必要时 Settings 帮助区）补充 `-dir` 可选工作目录说明，满足 PRD 验收标准 #8 与交互节要求
