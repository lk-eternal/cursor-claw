# 飞书通道

## 一、能力范围

飞书 WS、`LarkSender` 出站、Get/DONE、**合并 CardKit**、**回复卡编辑**、**Presentation CardKit**（p2p 全量 tool/thinking；群聊 shell + thinking）、assistant 流式 CardKit。

**不负责**：Daemon dispatch、凭据 UI、微信。

## 二、设计决策与取舍

- CardKit 流式/PATCH 降级（`lark-core.ts`）。
- **合并卡**单卡 PATCH（`renderMergeBatchCard`）；按钮占位，回调 T8。
- **静默窗口** `MERGE_QUIET_MS` 默认 2.5s；ready 时 processing 排队。
- **NF2**：活跃 MergeBatch 时 Presentation 首包 reply 到末条 inbound。
- **eligible**：主用户 p2p + 飞书群聊 `allowOthers`（S1.8）。
- **群聊 Presentation 门控**：shell 工具 + thinking CardKit；非 shell 工具抑制；p2p 全量不变（`isGroupChatPresentationEventAllowed` / `isGroupChatPresentationToolAllowed`；thinking 无门控）。
- **shell 工具卡**：`tool-presentation.ts` 解析 command/cwd/output，`lark-core.renderToolProgressCard` 渲染 `\`\`\`shell` 命令块与输出代码块。

## 三、服务端规则

- 群聊须 @；F1 由 daemon `buildEnqueueStatusText`。
- **F3**：`tryHandleMergePreviewReply` 命中 `mergeCardRegistry` → override，不入队。
- **合并卡**：预览条目 + 脚本文案（倒计时/排队/发送中）；edit 经 `replaceSessionUnclaimedMessages`。
- **工具/thinking/assistant**：Presentation → CardKit（群聊 shell + thinking，非 shell 工具抑制；p2p 全量）；assistant 转 stream-text（群聊/p2p 均保留）。

## 四、客户端流程

入站 → F1/合并卡 → 静默 → dispatch → SDK Presentation → CardKit 出站。

## 五、接口

| 能力 | 函数 |
|------|------|
| 合并卡 | `renderMergeBatchCard` |
| 工具卡 | `renderToolProgressCard`（shell 经 `buildShellToolCardMarkdown`） |
| thinking | `renderThinkingCard` |
| 流式 | `createStreamingCardEntity` 等 |
| F3 | `tryHandleMergePreviewReply` |

## 六、数据

`MergeBatch`、`mergeCardRegistry`、`SessionProgressState`（card/tool/thinking 字段）。

## 七、非功能与可观测

CardKit 失败降级；`presentation_failed`；edit 上限 30000 字。

## 八、推送

无。
