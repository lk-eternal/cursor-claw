# 飞书通道

## 一、能力范围

飞书 WS、`LarkSender` 出站、Get/DONE、**合并 CardKit**、**回复卡编辑**、**assistant 流式 CardKit**（stream-text）。

**Presentation 过程类**（tool/thinking）：飞书全通道（群聊 + 主用户 p2p）**不展示** CardKit，过程见桌面 SDK UI 日志。

**不负责**：Daemon dispatch、凭据 UI、微信。

## 二、设计决策与取舍

- assistant stream-text **首选 CardKit 流式卡片**（`streaming_mode`）；失败降级 `updateMessageContent` PATCH 或分段（`lark-core.ts`/`daemon.ts`）。
- **合并卡**单卡 PATCH（`renderMergeBatchCard`）；按钮占位，回调 T8。
- **静默窗口** `MERGE_QUIET_MS` 默认 2.5s；ready 时 processing 排队。
- **NF2**：活跃 MergeBatch 时 Presentation 首包 reply 到末条 inbound。
- **eligible**：主用户 p2p + 飞书群聊 `allowOthers`（S1.8）。
- **飞书过程 Presentation 门控**：全通道抑制 tool/thinking CardKit（`feishu-presentation-gate.ts`）；过程见 SDK UI 日志；ordering 闩锁仍更新。
- **PRESENTATION_ORDERING**：主用户 p2p 有 tool/thinking Run 时 assistant 延迟首建；纯对话立即建卡。

## 三、服务端规则

- 群聊须 @；F1 由 daemon `buildEnqueueStatusText`（`starting`/`processing`/`idle` 三态；排队数仅 unclaimed `.qmsg`）。
- **SDK 压缩/失败 notify（send-text）**：`summary-started` →「正在压缩上下文…」（不传 `stop_progress`，每 Run ≤1，`compressionNotified`）；Run 失败经 `formatUserSdkFailureMessage` 分类文案 + `stop_progress: true`；`summary-completed` 仅 UI 日志不发 IM。
- **冷启动首条**：应用重启后 phase Map 为空时默认 `idle`；stale `.claimed` 由 `cleanupOrphanClaimedOnColdStart` 回收，首条不误报「正在处理上一条」或虚假排队数。
- **F3**：`tryHandleMergePreviewReply` 命中 `mergeCardRegistry` → override，不入队。
- **合并卡**：预览条目 + 脚本文案（倒计时/排队/发送中）；edit 经 `replaceSessionUnclaimedMessages`。
- **tool/thinking Presentation**：飞书全通道抑制 CardKit 出站；SDK UI 日志保留；ordering 闩锁照常。
- **assistant stream-text（CardKit 首选）**：create→send→update→close 四步（`streaming_mode`/`card_id`/`stream_content`/`sequence` 递增）；State 记 `cardId`/`elementId`/`cardSequence`/`streamCardKitMode`；任一步失败或含 @ → PATCH/分段 fallback；ordering defer 同前。

## 四、客户端流程

入站 → F1/合并卡 → dispatch → Presentation → assistant CardKit 流式出站；压缩进行中与失败 notify 经 send-text；`final` 附上下文占用摘要（不可得时省略）。

## 五、接口

| 能力 | 函数 |
|------|------|
| 合并卡 | `renderMergeBatchCard` |
| 工具/thinking 卡渲染 | `renderToolProgressCard`、`renderThinkingCard`（飞书 Presentation 抑制时不调用出站） |
| CardKit 流式 | `createStreamingCardEntity`、`sendStreamingCardMessage`、`updateStreamingCardText`、`closeStreamingCardMode` |
| PATCH/分段 fallback | `sendStreamMessage`、`updateMessageContent`、`sendStreamSegments` |
| F3 | `tryHandleMergePreviewReply` |
| 门控 | `isFeishuProcessPresentationSuppressed`（`feishu-presentation-gate.ts`） |

## 六、数据

`MergeBatch`、`mergeCardRegistry`、`SessionProgressState`（流式 card 字段；tool/thinking 卡字段飞书抑制时不写入）。

## 七、非功能与可观测

CardKit 失败降级；须 **`cardkit:card:write`**；`presentation_failed`；edit 上限 30000 字；流式节流 500–1500ms。

## 八、推送

无。
