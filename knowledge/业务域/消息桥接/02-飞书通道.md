# 飞书通道

## 一、能力范围

飞书 WS、`LarkSender` 出站、Get/DONE、**合并 CardKit**、**回复卡编辑**、**assistant 流式 CardKit**（stream-text）。

**Presentation 过程类**（tool/thinking）：飞书全通道（群聊 + 主用户 p2p）**不展示** CardKit，过程见桌面 SDK UI 日志。

**不负责**：Daemon dispatch、凭据 UI、微信。

## 二、设计决策与取舍

- CardKit 流式/PATCH 降级（`lark-core.ts`）。
- **合并卡**单卡 PATCH（`renderMergeBatchCard`）；按钮占位，回调 T8。
- **静默窗口** `MERGE_QUIET_MS` 默认 2.5s；ready 时 processing 排队。
- **NF2**：活跃 MergeBatch 时 Presentation 首包 reply 到末条 inbound。
- **eligible**：主用户 p2p + 飞书群聊 `allowOthers`（S1.8）。
- **飞书过程 Presentation 门控**：群聊与主用户 p2p 统一抑制 tool/thinking CardKit 出站（`isFeishuProcessPresentationSuppressed`，`src/shared/feishu-presentation-gate.ts`）；Electron `postPresentationEvent` 不 POST，Daemon 静默 `{ ok: true }`；PRESENTATION_ORDERING 闩锁仍更新。过程见 SDK UI 日志（`pushUiLog [tool]`、`appendSdkLog [thinking]`）。取代 v1.6.1 群聊仅 shell 门控；微信不受影响。
- **PRESENTATION_ORDERING assistant defer（主用户 p2p SDK）**：`PRESENTATION_ORDERING` 默认开（`0`/`false` 回滚）；含 tool/thinking Run 时 assistant CardKit **延迟首建**（过程 idle 或 Run final 后释放），纯对话首 delta 仍立即建卡；群聊/CLI 不在 MVP。

## 三、服务端规则

- 群聊须 @；F1 由 daemon `buildEnqueueStatusText`（`starting`/`processing`/`idle` 三态；排队数仅 unclaimed `.qmsg`）。
- **冷启动首条**：应用重启后 phase Map 为空时默认 `idle`；stale `.claimed` 由 `cleanupOrphanClaimedOnColdStart` 回收，首条不误报「正在处理上一条」或虚假排队数。
- **F3**：`tryHandleMergePreviewReply` 命中 `mergeCardRegistry` → override，不入队。
- **合并卡**：预览条目 + 脚本文案（倒计时/排队/发送中）；edit 经 `replaceSessionUnclaimedMessages`。
- **tool/thinking Presentation**：飞书全通道抑制 CardKit 出站；SDK UI 日志保留；ordering 闩锁照常。
- **assistant stream-text**：群聊与 p2p 均 CardKit 流式 PATCH；主用户 p2p 且 ordering 开启、本 Run 已见过程事件时延迟首建（见上 defer），群聊与纯对话路径不变。

## 四、客户端流程

入站 → F1/合并卡 → 静默 → dispatch → SDK Presentation → assistant stream-text CardKit 出站（tool/thinking 仅 SDK UI 日志，无飞书过程卡）。

## 五、接口

| 能力 | 函数 |
|------|------|
| 合并卡 | `renderMergeBatchCard` |
| 工具/thinking 卡渲染 | `renderToolProgressCard`、`renderThinkingCard`（飞书 Presentation 抑制时不调用出站） |
| 流式 | `createStreamingCardEntity` 等 |
| F3 | `tryHandleMergePreviewReply` |
| 门控 | `isFeishuProcessPresentationSuppressed`（`feishu-presentation-gate.ts`） |

## 六、数据

`MergeBatch`、`mergeCardRegistry`、`SessionProgressState`（流式 card 字段；tool/thinking 卡字段飞书抑制时不写入）。

## 七、非功能与可观测

CardKit 失败降级；`presentation_failed`；edit 上限 30000 字。

## 八、推送

无。
