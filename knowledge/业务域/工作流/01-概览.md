# 工作流 · 概览

## 一、模块定位与边界

多节点 Agent 流水线：有序节点链 + MCP 流转。默认单会话连续执行；`isolated` 节点 spawn 独立 Agent。不负责通道连接与通用 Agent 调度（见 Agent 调度域）。

## 三、核心状态机/主流程

```mermaid
stateDiagram-v2
  [*] --> pending: createInstance
  pending --> running: startWorkflow
  running --> running: next/reject
  running --> completed: 末节点 next
  running --> failed: 超步数/重试
  running --> paused: recoverStale
  paused --> running: resumeWorkflow
```

## 五、关键约束

- `nodes` 顺序即执行顺序；驳回仅可回退到当前节点之前。
- `maxSteps` 默认 50；`maxRetries` 默认 2（计带 `rejectFromNodeId` 的历史）。
- 定义 YAML、实例 JSON；next/reject 在 `cursor-claw`，管理在 `cursor-claw-admin`。

## 八、全局非功能与可观测

- `recoverStaleInstances`：`running`→`paused`（API 已有，产品未接入）。
