# 知识地图

## 一、项目定位

**Cursor Claw**（v1.2.1）是飞书 & 微信 × Cursor AI 协作桌面应用，技术栈为 Electron + React + Tailwind。产品将 Cursor Agent 从本地 IDE 扩展为 7×24 远程数字雇员：用户通过飞书/微信收发消息，本机 Daemon 持久运行并自动重连 Agent。面向需要随时随地与 AI 协作、依赖多会话并行、定时任务与工作流自动化的开发者与团队。

## 三、工程组成

与 `kb.project.json` 的 `codeRoots` 对齐：

| 目录 | 说明 |
|------|------|
| `src/` | 应用源码：Daemon、MCP 服务、React 渲染端、共享模块 |
| `electron/` | Electron 主进程：会话调度、Agent 启动、配置、Cron |
| `resources/` | 资源模板：工作区注入、内置工作流等 |

工程平台分区（端侧约定，见 [工程平台/README](./工程平台/README.md)）：

| 分区 | 说明 |

| [Daemon 守护进程](./工程平台/Daemon守护进程/00-README.md) | 本机 HTTP/MCP、消息队列、通道桥接 |

## 四、外部依赖

| 类别 | 依赖 | 用途 |
|------|------|------|
| 飞书 | [飞书开放平台](https://open.feishu.cn/)、`@larksuiteoapi/node-sdk` | WebSocket 收消息、API 发送 |
| 微信 | 微信 iLink / ClawBot API | 扫码登录、长轮询收发 |
| Cursor | Cursor CLI、`@cursor/sdk` | Agent 启动、resume、SDK 模式 |
| MCP | `@modelcontextprotocol/sdk` | Daemon MCP 工具暴露 |
| 运行时 | Node ≥18、Electron 41 | 桌面壳与 Daemon 进程 |
| 其他 | `node-cron`、`yaml`、`electron-updater` 等 | 定时调度、工作流解析、应用更新 |

关键配置入口：根目录 `README.md`「平台接入配置」、Electron `config-store`、工作区 `.cursor/mcp.json`。
