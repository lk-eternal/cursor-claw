# Electron 桌面应用 · 概览

## 一、模块定位与边界

Cursor Claw 桌面端将 Cursor Agent 扩展到飞书/微信。Electron 负责可视化配置、spawn 守护进程、注入工作区 MCP/Rules/Skills，并通过 IPC 驱动 React UI。消息桥接与 MCP HTTP 由 Daemon 承担（见 Daemon 分区）。

## 三、核心状态机/主流程

```mermaid
stateDiagram-v2
  [*] --> AppReady: app.whenReady

  DaemonIdle --> DaemonStarting: startDaemon / 自动启动
  DaemonStarting --> DaemonRunning: lock 文件就绪
  DaemonRunning --> DaemonIdle: stop / shutdown
  DaemonRunning --> DaemonStarting: 异常退出自愈
  WindowShown --> Hidden: close=minimize
  Hidden --> WindowShown: 托盘/activate
```

## 五、关键约束

- 渲染进程 `contextIsolation: true`，仅 `window.electronAPI`。
- `--profile=xxx` 隔离 userData。
- Daemon 仅 `127.0.0.1`；默认端口 19528。

## 八、全局非功能与可观测

- 主进程未捕获异常写入 UI 日志；Daemon stdout 特殊前缀由 daemon-manager 解析广播。
- Daemon 60s 内异常退出最多自动重启 5 次。
